# MSN Milestone Suit

A native macOS app for writing documentation, keeping secrets locked inside documents, and tracking milestones.

## Features
- Google Docs style editor that saves as Markdown and exports PDF
- Locked secrets inside documents, unlocked with Touch ID or a master password
- Locked folders and encrypted sharing between MSN users
- Graph of linked documents, diagrams, and a milestone Gantt chart
- Runnable code blocks for JavaScript, TypeScript and Python

## Project layout
- `MSN/` Xcode project and app source
- `docs/` Project documentation

## Requirements
- macOS 26 or later
- Xcode 27 or later

## Privacy
Everything stays on the Mac. No accounts, no servers, no data collected.
